# social-content-studio

مهارة (Skill) لتوليد أفكار وصياغة محتوى السوشيال ميديا: ريلز، فيديو بلس (حتى 60 ثانية)، وكاروسيل.
النيشات: الشأن الفلسطيني، المحاسبة، الذكاء الاصطناعي والسوشيال ميديا. اللغة الافتراضية: فصحى مبسطة.

## المحتويات
- SKILL.md: ملف المهارة (التعليمات والمنطق كاملة).

## الاستخدام
ارفع المجلد كما هو (المجلد الذي يحوي SKILL.md) إلى المكان الذي يقرأ المهارات، أو اربط هذا المستودع.

## ملاحظات
- المهارة صياغة وأفكار فقط؛ لا تصمّم ولا تمنتج ولا تنشر.
- قاعدة التحقق بوضع التنبيه فقط: كل رقم أو ادعاء يُعلَّم [موثّق] أو [يحتاج تحقق] مع التاريخ.
